数据流:
=======
1. 请求进入 → 检查缓存 (fresh < 5分钟) → 直接返回
2. 缓存过期 → 聚合器尝试数据源1 → 验证 → 成功 → 返回 + 更新缓存
3. 数据源1失败 → 熔断/重试机制 → 尝试数据源2
4. 所有源失败 → 返回旧缓存 (stale < 1小时) → 避免空数据
5. 旧缓存也过期 → 返回空 DataFrame + 记录错误
