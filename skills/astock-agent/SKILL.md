# AStock-Agent A股游资分析助手

## Overview

这个 skill 用来处理"A股短线资金复盘"类任务。

它不是靠记忆聊行情, 而是先运行内置 Python 数据管线采集真实数据(行情/涨停池/炸板池/龙虎榜席位), 用透明的规则模型算出市场温度、情绪周期、板块强度、龙头评分, 最后在数据之上做推理和呈现。

双引擎架构:

- 数据规则引擎: `main.py` 管线, 产出 Markdown 报告 + 结构化 JSON
- AI 推理层: 配置了 `ASTOCK_LLM_API_KEY` 时由管线内置 LLM 生成; 未配置时由执行本 skill 的模型基于 `--json` 数据自行完成 AI 分析层(见 Workflow 第 4 步)

## When To Use

在下面这些场景触发:

- `今天复盘一下` `帮我做个复盘` `今日A股情绪怎么样`
- `现在是情绪周期的哪个阶段` `市场温度多少` `赚钱效应如何`
- `今天的连板梯队` `最高几板` `涨停分析`
- `当前主线是什么板块` `板块轮动到哪了`
- `今天的龙头是谁` `给龙头股打个分`
- `龙虎榜有什么游资动向` `XX股票的龙虎榜席位分析`
- `分析一下XXX这只票的资金行为` (个股模式)

不适用: 长线价值分析、基本面估值、港美股(本 skill 只覆盖 A 股短线资金行为)。

## How To Run

首次使用先确认依赖 (akshare/pandas/requests):

```bash
cd skills/astock-agent
pip install -r requirements.txt
```

常用命令 (在 `skills/astock-agent/` 目录下执行):

```bash
python main.py                    # 最近交易日全市场复盘 (自动落盘 Markdown)
python main.py --date 20260715   # 指定交易日复盘
python main.py --stock 600664    # 个股资金分析 (可加 --date)
python main.py --json            # stdout 输出结构化 JSON, 日志走 stderr
python main.py --no-ai           # 跳过内置 LLM 调用
```

可选 AI 配置 (OpenAI 兼容协议, DeepSeek/Kimi/通义/GPT 均可):

```bash
ASTOCK_LLM_API_KEY=sk-xxx
ASTOCK_LLM_BASE_URL=https://api.deepseek.com/v1   # 默认
ASTOCK_LLM_MODEL=deepseek-chat                     # 默认
```

报告输出在 `skills/astock-agent/reports/`, 历史数据自动存入 SQLite (`astock.db`)。

## Workflow

收到用户请求后按这个顺序执行:

1. 判断意图: 全市场复盘 / 个股分析 / 指定日期, 选择对应命令
2. 运行 `python main.py --json --no-ai` (个股则加 `--stock 代码`), 拿到结构化数据; 同时会生成完整 Markdown 报告
3. 读取生成的报告文件, 核对关键数字
4. 充当 AI 分析层: 基于 JSON 数据完成六节推理 —— 市场环境 / 资金方向 / 龙头判断 / 风险分析 / 明日观察 / 仓位建议。所有结论必须引用管线产出的具体数字, 不允许脱离数据发挥
5. 按 Output Format 呈现给用户, 并附上报告文件路径

连续使用效果更好: SQLite 会累积每日快照, 板块持续天数、温度趋势、晋级率对比都依赖历史数据, 连续运行数日后周期判断更准。

## Core Rules

- 研究资金, 不是预测价格; 研究概率, 不是追求确定; 控制风险优先于盈利
- 禁止保证盈利、承诺收益
- 禁止"必买""满仓梭哈"等确定性推荐
- 禁止预测确定性涨跌, 只给概率化、条件化判断(如"若竞价承接强则…否则…")
- 所有结论建立在管线采集的真实数据上, 不编造数据, 不凭记忆报行情
- 数据缺失时如实说明(如龙虎榜一般在收盘后 17:00~19:00 才公布, 盘中运行该节为空)
- ST/退市股已在管线内过滤, 不参与梯队与情绪统计
- 游资席位风格标签来自民间公开统计, 引用时注明可能存在误差
- 不向用户展示管线内部执行过程, 只呈现分析结果

## Output Format

默认先给结论清单, 再展开细节:

### 1. 盘面结论

- 情绪温度 / 市场状态 / 情绪周期 (如 `24/100 · 退潮 · 退潮期`)
- 当前主线与状态
- 市场龙头与评分
- 一句话应对策略

### 2. 核心数据

用紧凑的 Markdown 呈现:

- 涨停/跌停/炸板率/晋级率/市场高度
- 连板梯队 (高度降序)
- 板块强度表 (前5)
- 龙头评分表 (含优势/风险)
- 龙虎榜游资动向 (知名席位/资金类型/态度)

### 3. 风险与观察

- 风险提示 (数据触发, 不空喊)
- 明日观察计划 (主线跟踪/龙头接力/反包观察/规避方向)
- 仓位参考区间 + "仅供研究参考, 不构成投资建议"

## 失败降级策略

- 数据源多层回退已内置 (东财优先, 被限流自动切新浪), 个别维度缺失时报告会自动跳过并重新归一化权重, 不要因单一接口失败而中断
- 当日 15:00 前运行: 数据为盘中快照, 需向用户说明非收盘定稿
- 龙虎榜未公布: 明确告知公布时间, 建议晚间再跑一次
- 非交易日/数据未生成: 管线自动回退到最近交易日并在报告标注
- 如果管线彻底失败(如断网), 如实告知, 不要用记忆编造复盘

## Risk Note

这是资金行为研究工具, 不是投资建议系统。所有输出仅为公开数据整理与概率研究, 用户的交易决策与盈亏自负。
