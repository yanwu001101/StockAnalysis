# AStock-Agent 使用示例

这些示例展示 skill 的典型用法, 便于快速理解。

## 示例 1: 每日复盘

**输入**

```text
帮我复盘一下今天的A股
```

**执行**

```bash
python main.py --json --no-ai
```

**输出重点**

- 情绪温度 24/100 · 退潮 · 退潮期
- 涨停 41 / 跌停 33 / 炸板率 38% / 晋级率 13%
- 主线: 化学制药 (分化提纯), 核心 哈药股份 5板
- 龙头评分表 + 明日观察计划 + 仓位参考

## 示例 2: 情绪周期判断

**输入**

```text
现在市场情绪处于什么阶段? 能上仓位吗?
```

**输出重点**

- 周期判定 + 判定依据 (晋级率/高度变化/大面数量)
- 对应阶段策略与仓位区间 (仅供研究参考)

## 示例 3: 个股资金分析

**输入**

```text
分析一下哈药股份的资金行为
```

**执行**

```bash
python main.py --stock 600664 --json --no-ai
```

**输出重点**

- 4连板 · 龙头评分 92 (市场龙头)
- 龙虎榜: 买方席位结构、知名游资、资金类型与态度
- 风险: 买入集中度 / 知名席位兑现

## 示例 4: 指定日期复盘

**输入**

```text
帮我复盘 7月15日 的行情
```

**执行**

```bash
python main.py --date 20260715 --json --no-ai
```

## 示例 5: 龙虎榜游资动向

**输入**

```text
今天龙虎榜有什么游资在动?
```

**输出重点**

- 上榜家数 / 合计净买 / 游资活跃度
- 知名席位买入了哪些票 (如 中信上海溧阳路 买入 铂力特)
- 每只净买靠前个股的资金类型 (游资接力/机构主导/北向参与/散户博弈)
